    📚 Quick Cheat Sheet
    

      
\d — digit [0-9]
\w — word char [A-Za-z0-9_]
\s — whitespace

      
. — any char
^ — start $ — end
[] — character set

      
+ — 1 or more
* — 0 or more
? — 0 or 1
{2,4} — range

      
() — group / capture
| — OR
\b — word boundary
i — ignore case flag
